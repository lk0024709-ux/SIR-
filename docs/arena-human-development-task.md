SIR-Nano → SIR-Lite → SIR-Flash Lite → SIR-Flash → SIR-Pro → SIR-Pro+ → SIR-Pro Max → SIR-Ultra → SIR-Expert

The generations represent progressive cognitive development, analogous to human educational/professional growth. They are not simply parameter-size labels.

## Required developmental philosophy

SIR must develop as a broad generalist:

- complete Class 1–10 knowledge across major subjects
- then Class 11–12
- undergraduate foundations
- advanced/professional knowledge
- research methodology
- advanced interdisciplinary reasoning
- eventual expert specialization

The strongest cross-generation capability target is MASTER BRAINSTORMING:

Problem → clarify → decompose → retrieve → generate multiple hypotheses → connect domains → compare → challenge assumptions → verify → synthesize → explain.

Do not equate brainstorming with random idea generation. Measure novelty, relevance, feasibility, correctness, diversity and verification.

## Human-like learning loop

Implement the conceptual training loop:

Learn → Practice → Error Diagnosis → Correction → Application → Explanation → Verification → Transfer → Review → Progression

This is an engineering analogy, not a claim of biological human cognition.
